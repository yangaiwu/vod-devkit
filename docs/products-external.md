# 可归因产品一览（对外口径）

> 本节是**面向用户的产品定义层**：被问"XX 产品是什么"时，模型/客服只引用本节作答。
> 归因机制、VALID_PRODUCTS、白名单等属内部实现（见 proposal.md/design.md），
> **不进面向用户的回答**。
>
> 来源与状态：定义整理自公开资料，**待 VOD 团队复核确认**（AIShell 定义缺失的
> 文档 gap 由此节兜底，复核后以官方口径为准）。

| 产品名 | 一句话定义（对外口径） |
|---|---|
| CodeArts（码道） | 华为云软件开发生产线，一站式 DevOps 平台 |
| DataArts | 华为云数据治理与数据集成服务 |
| MaaS（ModelArts Studio） | 华为云大模型即服务平台 |
| OBS | 华为云对象存储服务 |
| AIShell | 华为云 AI Shell：智能命令行终端（云资源智能运维；定义待 VOD 团队复核） |
| OfficeClaw | 华为云 AI 办公助手类产品（定义待复核） |
| VOD | 用户声音分析平台（本反馈系统所属产品） |

## 面向用户问答纪律

1. 只回答产品定义与反馈入口，不提归因/白名单/配额等内部机制
2. 被问"我的反馈归到哪了"→ 答"已归到你反馈时所在的产品"，不给 key/档位细节
3. 失败话术见 SKILL.md F2（失败路径同口径：说人话，不暴露内部字段）
