# VOD评分规则

## 评分公式

总分 = 声音等级加权平均 + 场景范围 + 功能重要性 + 用户价值 + 友商对比

满分: 10.5分，下限: 1.0分

## 各维度得分表

### 声音等级加权平均 (0.0-5.0)

| 等级 | 得分 |
|------|------|
| L1 | 5.0 |
| L2 | 4.0 |
| L3 | 3.0 |
| L4 | 2.0 |
| L5 | 1.0 |

计算方式: Σ(等级得分 × 该等级VOD数) / 总VOD数

### 场景范围 (0.3-1.0)

| 关联声音数 | 得分 | 含义 |
|-----------|------|------|
| ≥5 | 1.0 | 大量用户 |
| ≥2 | 0.6 | 部分用户 |
| <2 | 0.3 | 特定场景 |

### 功能重要性 (0.5-1.5)

| 重要性 | 得分 |
|--------|------|
| 核心功能 | 1.5 |
| 重要功能 | 1.0 |
| 一般功能 | 0.5 |

### 用户价值 (0.0-1.5)

| 价值 | 得分 |
|------|------|
| 高业务价值 | 1.5 |
| 中业务价值 | 0.8 |
| 低业务价值 | 0.0 |

### 友商对比 (0.0-1.5)

| 对比情况 | 得分 |
|---------|------|
| 友商有我没有 | 1.5 |
| 友商部分支持 | 1.0 |
| 友商也没有 | 0.5 |
| 无竞品对比 | 0.0 |

## 优先级映射

| 总分 | 优先级 |
|------|--------|
| ≥8.5 | P0 |
| ≥7.0 | P1 |
| ≥5.5 | P2 |
| ≥4.0 | P3 |
| <4.0 | P4 |

## 体验评级

基于优先级分布计算:

| 条件 | 评级 |
|------|------|
| P0占比 ≥ 20% | 严重 |
| P0占比 ≥ 10% 或 P1占比 ≥ 30% | 预警 |
| P1占比 ≥ 20% | 正常 |
| 其他 | 良好 |

## 维度推断规则

当AI未给出维度判定时，按以下规则推断:

- 场景范围: 声音数≥5→大量用户, ≥2→部分用户, <2→特定场景
- 功能重要性: BUG数≥3→核心功能, ≥1→重要功能, 0→一般功能
- 用户价值: L1/L2数≥3→高业务价值, ≥1→中业务价值, 0→低业务价值

## 实现位置

- Java: `vod-system/backend/.../service/VodScoreService.java`
- 双算对比: Java端AnalysisService.parseWorkflowResults中自动执行
